# 繪本製作規格與 Codex 交接

本頁記錄已確認的繪本製作決定，供後續 13 本沿用。整理日期 2026-11-11。以使用者當次新指示及核定分鏡為準。

## 工作分工與交付
- 影片、原圖、逐字分鏡與經典研究可在原 ChatGPT 對話討論，Notion 保存核定內容。
- Codex 從 GitHub 最新 main 製作網站、測試、提交與發佈，沿用四聖諦現有閱讀器。
- 兩邊可協作。若在 ChatGPT 製作 ZIP，交接時提供基準 commit，由 Codex 檢查與目前 main 的差異再整合。
- 每次交付產生可下載 ZIP，記錄基準與發布 commit。ZIP、Notion 與 GitHub 各有用途，採用 Codex 也保留 ZIP 備份。

## 分鏡需記錄的資料
每幕或每個字幕切點記錄下表。幕數與繪本頁數分開統計，同一張圖可搭配多頁原字幕。

| 欄位 | 記錄內容 |
| --- | --- |
| 幕號與時間碼 | 影片起訖時間與字幕出現時間 |
| 繪本文案 | 原字幕逐字照錄，保留標點與順序 |
| 原經文 | 畫面下方原文、經號與來源連結 |
| 原圖 | 使用者檔名、可存取的來源與本地／GitHub 路徑 |
| 圖片尺寸 | 原始寬高，另記網頁輸出寬高 |
| 影片加字 | 是否在 DaVinci 等剪輯軟體另加文字 |
| 網頁疊字 | 字串、位置、方向、字色與相對大小 |
| 繪本呈現 | 原圖加文字、純文字、或移至閱讀原經 |
| 截圖用途 | 僅作影片對照，或有明確核准的正式替代用途 |
| 查核狀態 | 已對照／待確認及具體缺項 |

## 原圖與網頁文字
- 優先採用使用者原圖。影片多出文字時，先判斷為剪輯疊字，原圖仍有效。
- 苦諦、集諦、滅諦、道諦以 HTML／CSS 疊字，保留原圖解析度及內容。
- 對照影片確認疊字出現的幕與位置，圖上原有文字也要分辨，避免重複疊字。
- 影片截圖留作定位和比對。原圖缺漏時列出缺少的幕與檔名，先確認可用來源或向使用者補取，勿自行以低解析影片截圖替換。
- 不為了版面自行改寫或縮短文案。可拆成多頁，完整保留原字句和先後順序。
- 原經疑字或教義問題另列待查核，核准後才修改已定稿文字。

## 閱讀器共通規格
- 以四聖諦現有 book.js、book.css 與分鏡資料結構為基準，重用已完成的行為，後續有共用程式調整時同步回歸四聖諦。
- 圖片為閱讀主體，上方是白色繪本文案，下方是對應原經；覆在圖片上的文字使用半透明深灰底。
- 直式上一頁、下一頁、目錄與頁碼固定在可視畫面底部，內容區預留高度與裝置安全邊界，長經文可捲動。
- 橫式使用現有沉浸式版面。圖片維持比例完整置中，左右邊欄放上一頁、下一頁、回簡介、目錄、閱讀原經與展開經文，依可用空間調整。
- 文字和控制列不能互相遮蔽。橫直切換保留頁碼。瀏覽器全螢幕需使用者操作時，沿用可視區沉浸式版面。
- 經文展開有清楚的關閉入口，回簡介和閱讀原經可找到；大字、按鍵觸控區、鍵盤翻頁和左右滑動沿用現有設計。
- 心經文字可橫向捲動，操作經文捲動時不觸發繪本翻頁。
- 同一幕文案行數不同時，心經起始位置固定，不隨一行或兩行旁白上下跳動。

## 文字頁與片尾
- 心經使用真正的網頁文字，直書、由右往左，標題「般若波羅蜜多心經」獨立在最右邊。
- 經文字色沿用橘黃色，目前核定紅字範圍為「無苦集滅道。無智亦無得。以無所得故。」。
- 「溫柔起點」製作說明以原文字呈現，避免畫面圖片和下方文字重複。
- 影片片尾經典出處在 Notion 原片分鏡保留。繪本不再重做成最後一頁，內容整理到導讀的閱讀原經區，書架和閱讀器提供入口。
- 其他主題若有同類經文或片尾文字卡，依上述規格處理，不自動把心經內容加入每一本。

## 首頁、改版紀錄與驗收
- 14 本書的順序沿用首頁，完成一本才開放對應閱讀入口；其餘顯示鎖頭，仍能觀看對應影片。
- 完成一本的書架封面、導讀、繪本與閱讀原經需相互連通。
- 驗收以原字幕逐字比對、原圖來源和尺寸、疊字、長短經文、首頁／末頁、橫直切換與回簡介為重點。對實際測試、原始碼檢查與使用者回報分別註明。
- 每次發佈提供正式網址、PR／commit、驗證結果及 ZIP。從即將發布或已發布的確切 commit 打包，排除憑證與暫存檔。
- Notion 原有改版紀錄在 <mention-page url="https://www.notion.so/40bcf2ef57db81658247c1e8268c3ccd"/>，在該頁追加日期、改動原因、成果、驗證、commit 連結，保留舊紀錄。
- 能使用 Notion 工具時先開啟目標頁，補寫後回傳頁面連結。若該 Codex 任務沒有 Notion 工具，交付可貼上的改版內容並明確標示尚未寫入，再由具有 Notion 連線的對話更新。
- 外掛工具可用性、Notion 文件授權與雲端網路允許網域分別檢查，API 網域允許不等同取得應用授權。
